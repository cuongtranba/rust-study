# Rust Study

This repository contains my personal learning journey through the Rust programming language, following the official [Rust Documentation](https://doc.rust-lang.org).

## Projects

### 1. Hello World (`hello-world/`)
My first Rust program - a simple "Hello, world!" application to get familiar with basic Rust syntax.

### 2. Hello Cargo (`hello_cargo/`)
Introduction to Cargo, Rust's build system and package manager. This project demonstrates:
- Creating a new Rust project with Cargo
- Building and running projects with `cargo build` and `cargo run`
- Managing dependencies with `Cargo.toml`

### 3. Guessing Game (`guessing_game/`)
A number guessing game that demonstrates:
- Using external crates (rand)
- Handling user input
- Using match expressions for control flow
- Working with Result types and error handling
- Loop control structures

## Running the Projects

Make sure you have Rust and Cargo installed. You can install them from [rustup.rs](https://rustup.rs/).

To run any project:
```bash
cd <project-directory>
cargo run
```

To build without running:
```bash
cargo build
```
